# LLM Post-Training Lab

A learning-oriented research engineering project for building an end-to-end LLM post-training workflow.

## Goals

This project combines two learning tracks:

### LLM Post-Training

- Supervised Fine-Tuning (SFT)
- Group Relative Policy Optimization (GRPO)
- Evaluation

### Research Engineering

- Git and GitHub
- Python project management with uv
- Shell scripting and Make
- Testing and code quality
- SSH and remote GPU training
- tmux
- Docker

The project is developed incrementally as a capstone for learning modern AI research tooling.
